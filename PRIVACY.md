ScrubURLs protects and respects your privacy.
We do not collect any of your usage data. Furthermore, ScrubURLs has no home server nor embeds any kind of analytic hooks in its code.

The only time ScrubURLs connects to a remote server is to update the rules file and the associated hash file
(by default `rules2.clearurls.xyz`, operated by the ClearURLs project). You can replace the update addresses at any
time in the settings. A copy of the rules is bundled with the extension, so it works without ever contacting a server.

All settings, statistics and the (optional) log are stored locally in the browser's extension storage.
